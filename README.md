# 📅 Turnero Ultra Moderno - Dark Premium Edition

Un sistema web moderno, fluido y elegante de gestión y control de turnos diseñado bajo la estética **Dark Premium Glassmorphism** (Navy Blue & Gold). Desarrollo ligero, rápido y sin dependencias externas complejas, ideal para comercios, profesionales independientes, centros médicos y empresas de servicio.

> **Desarrollado por Patric Soft ®**

---

## 🚀 Características Principales

* **🎨 Diseño Glassmorphism de Alto Impacto:** Interfaz ultra moderna con efectos de transparencia, gradientes dorados y modo oscuro.
* **📱 100% Adaptable (Responsive):** Funciona a la perfección en teléfonos móviles, tablets y computadoras de escritorio.
* **💾 Persistencia de Datos Local:** Los datos se guardan de forma automática en `localStorage`, asegurando que no se pierda la información al cerrar el navegador.
* **📊 Métricas en Tiempo Real:** Panel superior que calcula al instante el total de turnos, confirmados y pendientes.
* **🔍 Búsqueda y Filtros Avanzados:** Buscador por nombre/servicio en tiempo real y filtrado por estado (*Pendiente, Confirmado, Cancelado*).
* **📲 Integración Directa con WhatsApp:** Botón de un solo clic en cada turno para enviar recordatorios y confirmaciones personalizadas a los clientes.
* **📥 Exportación de Reportes a CSV:** Descarga toda la base de datos de turnos para control interno, contabilidad o integración con Excel.
* **🔔 Notificaciones Flotantes (Toasts):** Sistema de alertas elegante para confirmar acciones sin interrumpir la experiencia de usuario.

---

## 🛠️ Tecnologías Utilizadas

* **HTML5:** Estructura semántica y accesible.
* **CSS3:** Variables CSS, Glassmorphism (`backdrop-filter`), CSS Grid/Flexbox y animaciones fluidas.
* **JavaScript (Vanilla ES6+):** Lógica nativa, manipulación dinámica del DOM, gestión de eventos y persistencia en `localStorage`.
* **Google Fonts:** Tipografía *Plus Jakarta Sans*.
